# Finding template — Room C

One finding per stage that actually fails. Empty stages are recorded as `control_held`.

```json
{
  "schema": "hyperlex.sacred_object.finding.v0.1",
  "title": "",
  "owasp_llm_top10_year": 2026,
  "owasp_id": "LLM01",
  "rag_section": 3,
  "atom_ref": "",
  "description": "",
  "reproduction": "steps against this harness, no payload recipe",
  "cia": { "c": "", "i": "", "a": "" },
  "remediation": "control assertion that failed",
  "class": "OBSERVED",
  "brier": null,
  "forecast_eligible": false
}
```

`reproduction` names fixture ids and stage checks. It does not include a reconstructable wrap.
