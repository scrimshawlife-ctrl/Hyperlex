# Contributing to Hyperlex-Hermes-Specs

## Philosophy
This repo is the single source of truth for **design and specification**.

Implementation details belong in the engine package. Changes here should drive implementation.

## How to Contribute
1. Open an issue or discussion first for significant changes.
2. Update relevant spec/roadmap file.
3. Keep receipts and examples up to date when behavior changes.
4. Reference arXiv papers or real data sources explicitly.

## Style
- Clear, evidence-bound language
- Use the exact JSON schema from SPEC.md
- Prefer "MUST / SHOULD / MAY" language for requirements

## Pull Request Process
- Link to relevant roadmap phase
- Include before/after receipt examples when possible
- Update ROADMAP.md status if a phase advances

Thank you for helping shape the memetic signal layer.
